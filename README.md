## 📖 About The Project

**Discover Bogura** is a modern district information portal designed to showcase the beauty, history, culture, people, institutions, and important places of Bogura district.

The platform allows users to explore different Upazilas of Bogura and discover useful information about:

- 🏙️ Upazilas
- 👨‍🎓 Famous People
- 🏫 Schools & Colleges
- 🕌 Madrasas
- 🏥 Medical Institutions
- 👮 Police Stations
- 🚒 Fire Service Offices
- 🏛️ Government Institutions
- 🏞️ Tourist Attractions
- 🍲 Traditional Foods
- 🌊 Rivers
- 📍 Important Places

The goal is to create a simple and user-friendly digital platform where anyone can easily learn about Bogura.

## ✨ Features

### 🏠 Home Page

- Attractive hero section
- Introduction to Bogura district
- Featured Upazilas
- Popular places
- Important information
- Responsive design

### 🗺️ Upazila Explorer

Users can explore the different Upazilas of Bogura, including:

- Adamdighi
- Bogura Sadar
- Dhunat
- Dhupchanchia
- Gabtali
- Kahaloo
- Nandigram
- Sariakandi
- Shajahanpur
- Sherpur
- Shibganj
- Sonatala

### 🏛️ Category-Based Information

The application organizes district information into different categories, making it easy to discover specific information.

### 🔎 Details Pages

Users can view detailed information about individual places and institutions.

### 📱 Responsive Design

The website is fully responsive and optimized for:

- 📱 Mobile
- 💻 Desktop
- 📟 Tablet

### 🔐 Authentication

Firebase Authentication is used for secure user authentication.

### ⚡ Fast Data Fetching

TanStack Query is used for efficient server-state management and API data fetching.

### 🚨 User Feedback

SweetAlert2 is used to provide interactive success, warning, and error messages.
